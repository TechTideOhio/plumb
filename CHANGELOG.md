## [0.1.0] - 2026-11-03

### Added
- Initial release of `plumb` (Tool 11 in The Complete TideOS Eval Kit).
- Paired statistical significance testing on identical benchmark examples.
- Single-proportion Wald and Wilson score confidence interval calculators.
- 2x2 discordance matrix and paired variance reduction factor engine.
- Exact binomial McNemar test with Lanczos log-gamma cumulative distribution.
- Deterministic SplitMix64 non-parametric bootstrap (percentile and BCa intervals).
- Paired sign-flip permutation test and Wilcoxon signed-rank test.
- Two One-Sided Tests (TOST) equivalence and non-inferiority evaluator.
- Benjamini-Hochberg False Discovery Rate and Holm-Bonferroni correction.
- Closed-form sample size power and Minimum Detectable Effect (MDE) solver.
- Sequential SHA-256 Merkle provenance hash chaining for evaluation pairs.
- sha256-framed-v1 cryptographic lockfile generator and verifier.
- 8-point repository hygiene and strict zero em-dash and en-dash auditor.
- Terminal bell alert on statistical noise or regression violations.
